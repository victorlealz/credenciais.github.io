# Página de identificação — Victor

Site estático, simples e preparado para publicação no GitHub Pages.

## Arquivo principal

Todo o site está em `index.html`.

Para alterar os dados, abra o arquivo e procure o comentário:

```html
DADOS: edite somente os textos abaixo quando necessário.
```

Para mudar as cores, altere as variáveis no bloco `:root` no início do CSS.

## Publicação no GitHub Pages

1. Crie um repositório chamado `SEUUSUARIO.github.io`.
2. Envie `index.html` para a raiz do repositório.
3. Acesse `Settings` → `Pages`.
4. Em `Source`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve.
7. O endereço será `https://SEUUSUARIO.github.io/`.
